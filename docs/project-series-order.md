# 프로젝트 연재 정렬

프로젝트 카테고리 목록과 게시글 하단의 이전·다음 링크는 같은 프로젝트의 연재 번호 오름차순으로 표시한다. 발행일·파일명·제목·주소는 정렬 목적으로 변경하지 않는다.

- 적용 범위: 첫 카테고리가 `2.PROJECT`인 글.
- 프로젝트 구분: 두 번째 카테고리. 상위 PROJECT 목록은 카테고리 번호 순서로 묶는다.
- 연재 번호: 제목 시작의 `01. `, `02. ` 형태. 숫자로 비교하므로 `2. `도 `10. `보다 앞선다.
- 번호 없는 글: 해당 프로젝트의 번호 있는 연재 다음에 표시한다. 기존 Parser 비교 글의 제목과 주소는 유지한다.
- 단일 글, 연재 첫 글·마지막 글에서는 존재하지 않는 이전·다음 버튼을 비활성화한다.
- 홈·태그·일반 학습 카테고리와 비프로젝트 글의 탐색은 기존 날짜 기반 동작을 유지한다.

구현은 `_plugins/project-post-order.rb`, `_layouts/category.html`, `_includes/post-nav.html`에 한정한다. 테마 업데이트 시 두 오버라이드 템플릿을 테마 원본과 대조한다.

검증:

```shell
bundle exec ruby tools/tests/test_project_post_order.rb
bundle exec jekyll build
bundle exec htmlproofer _site --disable-external
```

게시물 코드 블록은 설명·당시 실험 기록이며 이 사이트의 실행 코드가 아니다. 사이트 빌드 통과를 해당 코드의 기능 테스트나 당시 벤치마크 재현 성공으로 해석하지 않는다.
